---
name: get-session
description: Get full session details with message snippets
---

Get detailed information about a specific session.

1. User must provide a `session_id` (UUID)
2. Use MCP tool `get_session` with the provided session_id
3. Return session metadata and message snippets

Example:
- `/get-session 7c43201a-f0b0-43e9-a49d-d87cb7cac2b5`
